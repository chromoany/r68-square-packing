# Fonts for this Chinese preprint

These four renamed TrueType subsets are derived from Noto Serif SC and Noto Sans SC. They contain the characters used in this manuscript and its figure labels, with static weights 400 and 600. Family names are R68 Serif SC and R68 Sans SC. They are supplied under SIL Open Font License 1.1; see LICENSE.txt and font-provenance.json.

The subsets make this source project independent of installed Chinese system fonts. If new Chinese text is added, regenerate the subsets from the full Noto fonts or replace the font declarations with an installed full font. Latin text and mathematics use the TeX Live fonts declared in preprint-style.tex.

Upstream font collections: https://github.com/notofonts/noto-cjk and https://github.com/google/fonts. The font license applies only to these font files and is distinct from the manuscript and proof-program rights.
